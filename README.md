A one-line office-life joke for the Make.fun competition
[Make the AI Judge Laugh](https://make.fun/bounty/u-alfasurya91-make-the-ai-judge-laugh-6ed40225).

`main.py` writes the joke — one line, under 200 characters — to
`/output/entry.txt`:

> The printer worked first try today, so IT seized it for questioning.

The turn: a working office printer is such an anomaly that IT treats the
machine itself as the suspect. True to office life, surprising, tight,
and original.

Run it:

```bash
python3 main.py
cat /output/entry.txt
```
